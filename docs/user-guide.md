# 闲鱼经营自动化中枢：完整使用手册

这份手册按“第一次只做一次”和“以后每天重复”的顺序编写。系统在本机运行，
不会替你登录账号、处理验证码，也不会在没有人工复核和批次审批时发布商品。

## 一眼看懂

```text
第一次安装并配对
        ↓
每天启动本地控制台
        ↓
导入自有或已授权商品
        ↓
生成文案和 3 张水印图
        ↓
人工逐条复核并批准本批次
        ↓
在空白发布页运行预检
        ↓
人工打开发布总开关
        ↓
扩展依次填表并核对回执
        ↓
人工关闭发布总开关并备份
```

## 第一次使用：只需完成一次

### 1. 安装

```bash
git clone https://github.com/harringtonwalker/xianyu-automation.git
cd xianyu-automation
./scripts/setup.command
```

### 2. 启动控制台

```bash
./scripts/start.command
```

浏览器打开 `http://127.0.0.1:8766`。控制台只监听本机地址，默认发布总开关
处于关闭状态。

### 3. 加载 Chrome 扩展

1. 打开 `chrome://extensions`；
2. 开启“开发者模式”；
3. 点击“加载已解压的扩展程序”；
4. 选择当前项目的 `extension/` 文件夹；
5. 保留这个文件夹的原路径。删除或移动后，Chrome 需要从新路径重新加载。

### 4. 配对扩展

1. 在控制台“品牌与扩展配对”区域复制配对令牌；
2. 打开扩展的“选项”页；
3. 本地服务地址保持 `http://127.0.0.1:8766`；
4. 粘贴令牌；如需从本人闲鱼个人页导入，再填写本人 `userId`；
5. 点击“保存并测试连接”。

配对令牌相当于本机发布队列钥匙。不要截图、发群、写进文档或提交到 Git。
如果密码管理器粘贴成一排 `••••`，请回到控制台重新复制真实令牌，不要复制
密码框的遮罩字符。

### 5. 完成发布前预检

保持同一个 Chrome 已登录闲鱼，打开空白
`https://www.goofish.com/publish` 页面，从扩展运行语义预检。预检通过后，
控制台会显示当前页面契约和有效期。页面发生变化或预检过期时必须重做。

## 每天怎么使用

### 开始工作

1. 运行 `./scripts/start.command`，打开 `http://127.0.0.1:8766`；
2. 确认同一个 Chrome 已登录正确的闲鱼账号；
3. 查看扩展是否显示“已配对”，发布总开关必须仍为关闭；
4. 检查品牌名、水印文字和本批次商品来源。

### 准备内容

5. 导入 CSV/JSON、自有闲鱼库存或已登录淘宝“我的商品”；
6. 点击“生成全部待处理内容”；
7. 逐条打开任务，完整检查商品事实、标题、文案、价格、发货方式和 3 张图片；
8. 只有内容完全正确时，输入 `确认已核对完整文案与商品事实`；
9. 勾选本次要处理的任务，按页面要求输入 `确认发布N条`。

### 运行发布队列

10. 打开一个新的空白 `https://www.goofish.com/publish` 页面；
11. 运行扩展预检；如果上次预检已超过 24 小时，必须重新预检；
12. 控制台确认本批次、任务数量和页面契约后，输入 `启用自动发布`；
13. 保持 Chrome 和本地服务运行，观察每条任务的状态与严格商品回执；
14. 批次完成后输入 `关闭自动发布`，再运行 `./scripts/backup.command`。

每一个新批次都需要重新复核和批准。系统不会因为昨天发布成功，就在今天绕过
人工确认。

## 状态怎么看

| 状态 | 你要做什么 |
|---|---|
| `INGESTED` | 等待生成内容 |
| `PENDING_APPROVAL` | 打开任务，完整复核后决定是否批准 |
| `APPROVED` | 已进入队列；发布总开关关闭时不会执行 |
| `RUNNING` | 保持页面和服务运行，不要重复点击 |
| `AWAITING_RECEIPT` | 已触发提交，等待同一页面回执，不要重试 |
| `PUBLISHED` | 核对商品 URL、item ID、标题和价格 |
| `BLOCKED` | 查看阻断原因；回执不确定时错误码为 `RECEIPT_UNCERTAIN`，必须先人工对账 |
| `FAILED` | 核查失败原因，修正后重新复核和批准 |
| `SUPERSEDED` | 旧修订已失效，使用最新修订 |

## 出现异常怎么办

| 现象 | 正确处理 |
|---|---|
| 扩展连接失败 | 确认服务正在运行、地址是 `127.0.0.1:8766`，再从控制台重新复制令牌 |
| 令牌粘贴后显示 `••••` 并报 header 错误 | 复制到了密码框遮罩字符；回控制台重新复制真实令牌 |
| Chrome 找不到扩展 | `extension/` 被移动或删除；从当前真实路径重新“加载已解压的扩展程序” |
| 预检过期或契约变化 | 停止发布，在新的空白发布页重新预检 |
| 出现验证码或风控 | 不绕过；人工完成平台要求后重新核查任务和预检 |
| 图片上传证据不足 | 不点击发布；检查图片和网络，再重新批准任务 |
| 已提交但没有确定回执 | 去“我的闲鱼”人工对账；确认未发布前不要重试 |
| 错价、错文案或错图 | 立即关闭发布总开关，修订商品并重新走完整复核 |

## 竞品信息的边界

当前系统没有实现“复制竞争对手商品”。允许单独建设的方向是公开市场情报：
价格区间、类目、上新频率和常见卖点关键词，用于分析趋势和生成差异化策略。
这些数据必须与发布队列隔离。

以下行为不属于本项目能力：复制竞品标题或描述、下载并复用竞品图片、去除他人
水印、绕过登录/验证码/限流/风控、批量搬运，或把竞品素材直接变成待发布商品。

## 收工、备份和恢复

正常收工：

```bash
./scripts/backup.command
```

先做无写入恢复演练：

```bash
./scripts/restore.command /完整路径/backups/YYYYMMDD-HHMMSS --check-only
```

正式恢复会先校验备份并保留当前 `data/` 作为可回滚目录。不要手工复制正在使用的
SQLite 文件，也不要把 `data/`、`backups/`、日志、令牌或商品素材提交到 Git。
